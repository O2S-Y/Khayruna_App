# Khayruna (خيرنا)

> **Where club conversations become actions.**
> Khayruna uses AI to transform group discussions and messaging threads into structured topics, actionable tasks, and formal project initiatives.

---

## Features

- **Conversations to Actions:** Automatically extract tasks, action items, and structured ideas from chat threads.
- **Task Management:** Real-time board to assign, track, and monitor collaborative initiatives.
- **Ideas Incubator:** Propose, vote on, and mature concepts into community projects.
- **Interactive Dashboard:** High-level overview of team progress, active members, and milestone achievements.
- **Clean Responsive UI:** Modern minimalist interface built with Tailwind CSS and dynamic themes.

---

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Frontend Library:** [React](https://react.dev/)
- **Styling:** CSS & [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** SVG Icon system

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   \\\ash
   git clone https://github.com/O2S-Y/Khayruna_App.git
   cd Khayruna_App
   \\\

2. Install dependencies:
   \\\ash
   npm install
   \\\

3. Run the development server:
   \\\ash
   npm run dev
   \\\

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
